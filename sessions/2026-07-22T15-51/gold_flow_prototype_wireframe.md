# Gold Tier Flow Prototype Wireframe: The Shield of Assurance

## 🎨 Design System Reference
*   **Primary Color:** Deep Teal (`#004D40`)
*   **Accent Color (Premium/Success):** Gold (`#FFD700`)

## 🖼️ Flow Breakdown
### Phase 1: Safety Check & Login (The Gate)
*   **Layout:** Centered, Minimalist.
*   **Key Element:** Top Banner - **Stability Indicator Bar**. Deep Teal 배경 위에 Gold 색상의 `Stability: PASS (P0)` 배지를 고정 배치.

### Phase 2: Real-time Data Dashboard (The Core)
*   **Layout:** Symmetric split (Left: Metrics, Right: Stream).
*   **Key Element - Latency Gauge:** 화면 상단 중앙에 현재 $Latency_{ms}$를 Gold 색상의 게이지 바로 표시. 목표 지연 시간(예: 50ms)을 초과하면 경고색으로 즉시 전환.
*   **Data Visualization:** 인슐린 데이터는 Deep Teal 카드 형태로 명확하게 구분하여 표시.

### Phase 3: Risk vs. Reward Analysis (The Assurance)
*   **Layout:** Bottom section focus.
*   **Key Element - ROI Visualizer:** $Risk Score$와 $P_0$의 관계를 보여주는 선형 그래프. Gold 색상의 성공 영역을 강조하여 안정성이 수익에 미치는 긍정적 영향을 시각화.

### Phase 4: System Status Feedback (The Feedback)
*   **Layout:** Persistent Widget (우측 하단).
*   **Content:** 실시간 $P_0$ 및 $Latency$ 상태를 아이콘과 함께 표시하여 지속적인 안정성을 강조.
