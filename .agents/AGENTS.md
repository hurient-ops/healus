<RULE[git_safety]>
- 깃허브(GitHub)에서 브랜치를 가져오거나(pull, fetch), 파일을 덮어쓰거나(checkout, reset), 코드를 병합(merge)하는 등 기존 로컬 작업물에 영향을 주거나 유실을 발생시킬 수 있는 Git 작업을 수행하기 전에는 반드시 사용자에게 명시적으로 수행할 작업과 그 영향을 설명하고 동의를 구해야 합니다.
- **예외 및 명시적 규칙:** `healus-backend`와 `healus-web` 프로젝트에 대한 깃허브 업로드(add, commit, push) 작업은 사용자 동의 없이 에이전트가 알아서 수행해도 됩니다.
- **엄격한 규칙:** 반면, 모바일 앱인 `healus` 폴더의 코드 변경 사항을 깃허브에 올릴 때에는 **항상, 예외 없이** 사용자에게 사전 승인(컨펌)을 받아야만 합니다.
- 사용자가 허락하기 전까지는 절대로 임의로 `healus` 폴더의 코드를 덮어쓰거나 변경하는 Git 명령어를 실행하지 마세요.
</RULE[git_safety]>
