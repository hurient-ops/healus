# 히스토리 화면 커스텀 달력 도입 및 레이아웃 최적화 구현 계획

본 계획서는 히스토리 화면의 날짜 선택 방식을 **'년/월/일' 순서의 한글 표기** 및 **클릭 시 펼쳐지는 모던 커스텀 달력(Calendar picker)** 형태로 전면 보완하고, 차트와 하단 수치 표를 압축하여 전체 UI가 모바일 뷰포트 내에 스크롤 없이 알맞게 위치하도록 개선하기 위한 방안을 정의합니다.

## User Review Required

> [!IMPORTANT]
> - **커스텀 달력(Calendar Dropdown) 구현**: 브라우저 기본 데이트피커 대신, 날짜 영역을 누르면 그 자리에 예쁘게 생성되는 커스텀 달력 팝업을 구축합니다. 날짜가 그리드로 배치되어 원하는 일자를 탭하는 즉시 차트가 갱신되고 달력이 닫힙니다.
> - **'년/월/일' 정렬 표기**: 중심 날짜 선택 텍스트가 영어식 기호 대신 `YYYY년 MM월 DD일` 순서의 자연스러운 한국어 포맷으로 표기되도록 합니다.
> - **수치 표 및 차트 높이 압축**: 차트 높이를 `200px`로 내리고 테이블 셀 크기를 타이트하게 줄여 하단 네비게이션바 바로 위에 전체 레이아웃이 꽉 들어차도록 화면 면적을 최적화합니다.

## Proposed Changes

### [UI and Application Core]

#### [MODIFY] [ui_design/history/code.html](file:///e:/projects/healus/ui_design/history/code.html)
- **커스텀 달력 피커 디자인 및 스크립트 작성**:
  - 기존 `<input type="date">`를 완전히 대체하는 커스텀 날짜 선택 버튼(`id="date-display-btn"`)을 만듭니다. 버튼 내부 텍스트는 `2026년 05월 28일` 형태로 실시간 노출됩니다.
  - 버튼 클릭 시 바로 밑에 열리는 절대좌표 기반 달력 컨테이너(`#custom-calendar-dropdown`)를 디자인합니다.
  - 달력 헤더에 이전달/다음달 이동 버튼 및 요일 라벨(일~토)을 배치하고, 날짜 영역을 7열의 그리드로 렌더링합니다.
  - 현재 선택된 중심 날짜는 테마 컬러(`#509194`)로 강조 표시하고, 날짜 클릭 시 해당 일자로 중심 날짜를 갱신하며 차트를 리렌더링합니다. 바깥 영역을 누르면 달력이 닫히도록 마킹합니다.
- **차트 높이와 Y축 눈금선 핏팅**:
  - 차트 전체 영역 높이를 `h-[200px]`로 축소합니다.
  - Y축 좌측 수치들(100, 80, 60, 40, 20, 0)을 `h-[200px]` 높이 내에 Flex column 구조(`justify-between`)로 균등 분할 배치하여 차트 안쪽 눈금선들과 완벽히 일렬 매칭되도록 조치합니다.
- **테이블 압축화**:
  - 하단 기초, 식사, 추가 주입수치 테이블의 셀 패딩을 `p-2`에서 `p-1`로 대폭 축소하고 글자 크기를 `text-[9px]`로 통일하여 세로 사용 공간을 컴팩트하게 절약합니다.
