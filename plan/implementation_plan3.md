# 하단 네비게이션바 고정 최적화 구현 계획

본 계획서는 웹뷰 화면 비율 조절 과정에서 일부 기기 해상도 상하 영역이 잘리거나, 하단 네비게이션 탭바가 가려지는 문제를 해결하기 위해 가로폭 기준 비례 조절 및 세로 동적 계산 기법을 도입하여 하단 탭바를 언제나 화면 하단에 완벽히 고정하기 위한 구현 방안을 정의합니다.

## User Review Required

> [!IMPORTANT]
> - **가로 기준 비례 및 세로 동적 가변 스케일링**: 기기 화면의 가로폭(`winW`)을 기준으로 스케일 팩터를 고정 적용하고, 세로 높이는 기기 가용 높이(`winH / scale`)만큼 동적으로 계산해 `body` 높이로 주입합니다.
> - **하단 탭바/네비게이션 완벽 고정**: 이 기법을 적용하면 기기 해상도 비율과 관계없이 웹뷰 내부에 불필요한 스크롤이 발생하지 않으며, 아래 네비게이션바(`nav`, `footer`)가 상시 화면 맨 밑바닥에 오차 없이 고정됩니다.

## Proposed Changes

### [UI and Application Core]

#### [MODIFY] [lib/main.dart](file:///e:/projects/healus/lib/main.dart)
- **`onPageFinished` 스크립트 수정**:
  - `transform-origin`을 `top left` 기준으로 지정하여 스케일 밀림을 방지합니다.
  - 가로 기준폭(`390px` 또는 `393px`)을 기기 가로폭으로 나눈 비율(`scale = winW / baseW`)로 전체 레이아웃을 스케일링합니다.
  - 세로 높이는 기기 가용 높이를 스케일로 역산한 값(`winH / scale`)으로 `body`에 강제 주입하여, 스케일링 후의 높이가 실제 화면 높이(`winH`)와 100% 일치하도록 처리합니다.
  - 이 늘어난 높이의 밑바닥(`bottom: 0`)에 하단 고정 요소(`nav`, `footer`)가 절대 좌표로 정렬되게 하여 잘림 현상을 원천 방지합니다.
  - 본문 영역(`main`)은 헤더와 하단바를 제외한 나머지 영역만 유연하게 차지하며, 본문 내에서만 개별 스크롤(`overflow-y: auto`)되도록 보장합니다.
